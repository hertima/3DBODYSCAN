## Commands

```bash
npm run dev        # Start dev server (Vite + TanStack Start, exposes on 0.0.0.0)
npm run build      # Production build (outputs dist/client + dist/server)
npm run lint       # ESLint
npm run format     # Prettier
npm run deploy     # Deploy to Cloudflare Workers (requires built dist/)
```

Environment: copy `.env.example` to `.env` and fill `VITE_FIREBASE_*` vars and `OPENAI_API_KEY`.

## Architecture

**ZYROX 3D Body Scanner** is a PWA fitness app with AI coaching. It is deployed as a Cloudflare Worker (SSR) serving a React SPA.

### Tech stack

| Layer | Technology |
|---|---|
| Framework | TanStack Start (TanStack Router + React 19) |
| Styling | Tailwind CSS v4 — semantic CSS custom properties (`var(--primary)`, `var(--cyan)`, `var(--surface)`, `var(--border)`, etc.) |
| Auth + DB | Firebase Auth + Firestore |
| AI | OpenAI GPT-4.1-mini — proxied through `vite.config.ts` in dev, Cloudflare Worker in prod |
| Video | Remotion (`src/remotion/`) |
| Deploy | Cloudflare Workers via Wrangler |

### Routing

File-based routing via TanStack Router. Routes live in `src/routes/`. **Never edit `src/routeTree.gen.ts` manually** — it is auto-generated by the Vite plugin on each build/dev start.

Route hierarchy:
- `/` — landing / login (`index.tsx`, `criar-conta.tsx`, `recuperar-senha.tsx`)
- `/onboarding/$step` — multi-step onboarding (steps 1–N)
- `/paywall` — subscription gate
- `/app` — authenticated shell (`app.tsx`) — guards all sub-routes via `onAuth`
  - `/app/` — dashboard (`app.index.tsx`)
  - `/app/treinos`, `/app/treino/$id` — workout plans and active session
  - `/app/exercicios`, `/app/exercicio/$id` — exercise library and detail
  - `/app/analytics` — charts and progress
  - `/app/corpo` — body measurements + nutrition (tabs)
  - `/app/nutricao` — AI-generated 12-week meal plan
  - `/app/perfil`, `/app/configuracoes` — profile and settings
  - `/app/historico/$id` — past session detail

### State management

There is no Redux or Zustand. State is split into two layers:

1. **`localStorage` (prefixed `zyrox.*` or `zyrox-`)** — primary runtime state. All onboarding data, workouts, schedule, periodization, history, and nutrition are stored here under these prefixes.
2. **Firestore `localState` collection** — cloud backup of the same localStorage keys. `src/lib/firestore-local-state.ts` monkey-patches `localStorage.setItem`/`removeItem` to auto-sync managed keys to Firestore, and `restoreLocalStateFromFirestore` pulls them down on login.

The `useTrainingState` hook is the main read API over localStorage for training data. `useGamification` derives XP, level, streak, achievements, and missions from `useTrainingState`.

### Auth flow

`app.tsx` calls `onAuth` (Firebase `onAuthStateChanged`) inside a `useEffect`. If no user → redirect `/`. If user but not onboarded → redirect `/onboarding/$step/1`. Once onboarded, starts Firestore autosync and realtime listener.

Onboarding state shape is defined in `src/lib/onboarding.ts` (`OnboardingState`), serialized to localStorage under a single key, and also written to Firestore via `src/lib/firestore-profile.ts`.

### AI / API endpoints

In **dev**, `vite.config.ts` registers a `devApiPlugin` Vite middleware that intercepts `POST /api/*` requests and proxies them to OpenAI:
- `/api/chat-stream` — streaming AI coach chat (SSE)
- `/api/ai-workout` — AI-generated workout selection (JSON)
- `/api/meal-plan` — 12-week meal plan generation (JSON)
- `/api/analyze-image` — body or food photo analysis (JSON)

In **production**, these same routes are handled by the Cloudflare Worker entry (`src/server.ts`).

The AI coach persona is **ZYROX AI Coach** (GPT-4.1-mini). Prompts and system instructions are built inline in `vite.config.ts`.

### i18n

Five locales: `pt` (default), `es`, `en`, `fr`, `de`. The active locale is stored in localStorage and read via `getStoredLocale()` from `src/lib/locale.ts`. Copy strings for each screen live in `src/lib/app-copy.ts` and `src/lib/training-i18n.ts`. Changing locale triggers `window.location.reload()`.

### Exercise data

Two catalogs: `src/data/musculacao-principal-catalog.ts` (gym) and `src/data/calistenia-pura-catalog.ts` (bodyweight). The unified lookup is `getExercise(id)` from `src/data/library.ts`. Exercise video files are large `.mp4` assets stored in `dist/client/`.

### Remotion

Video compositions in `src/remotion/compositions/` generate shareable video clips (workout summary, body evolution, etc.). The `ShareVideoButton` and `VideoPlayerModal` components render these via `@remotion/player`.

### Deployment

GitHub Actions (`.github/workflows/deploy.yml`) builds on push to `main` and deploys to Cloudflare Workers. The `dist/server/wrangler.json` worker name is patched post-build. Manual deploy: `npm run build && npm run deploy`.
